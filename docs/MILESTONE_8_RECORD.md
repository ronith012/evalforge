## Limits to note

1. **The schema checker is ours, not a standard implementation.** `tests/minimal_schema.py` supports the keywords the
   schema uses and refuses any other keyword. It does not implement the whole of JSON Schema. Validation against a full
   reference validator has not been done, because that would add a dependency that needs verification first (G-1).
2. **Banned-claims scan is a heuristic.** It looks for listed phrases within a window of text, and a negation nearby
   exempts a match. It can miss other wordings, and it can exempt a phrase that is negated in a different sense.
3. **The golden file is a snapshot.** It was generated by the code and then reviewed by hand. It proves the output has
   not changed since review; it does not prove the output is correct.
